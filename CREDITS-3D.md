# Aset 3D Juragan Kost

Model bangunan berikut berasal dari **Codels**, dirilis dengan [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

| Model | Sumber | Pemakaian |
|---|---|---|
| Cottage | [Codels](https://codels.download/models/cottage) | Kos awal dan rumah tetangga |
| Farmhouse | [Codels](https://codels.download/models/farmhouse) | Kos level 2 dan rumah tetangga |
| Modern House | [Codels](https://codels.download/models/modern-house) | Kos level 3 dan rumah tetangga |
| Japanese House | [Codels](https://codels.download/models/japanese-house) | Rumah tetangga |
| Oak Tree | [Codels](https://codels.download/models/oak-tree) | Pepohonan sekitar kos |
| Sedan | [Codels](https://codels.download/models/sedan) | Mobil di tepi jalan |

Model GLB dikonversi ke mesh ringkas dan disesuaikan skala serta materialnya. Mesh yang sama dipakai oleh model Three.js dan renderer CPU. Tidak diperlukan CDN model saat bermain.

## Kebun dan lapak

[Farm Kit oleh Codels](https://codels.download/collections/farm-kit), CC0 1.0: Wheat Patch, Carrot, Pumpkin, Wooden Fence, Scarecrow, Wicker Basket, dan Chicken. Geometri dikonversi ke mesh ringkas dan disesuaikan skalanya untuk kebun.
